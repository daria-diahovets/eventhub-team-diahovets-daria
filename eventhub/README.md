### Курс: Веб-технології та веб-дизайн

Наскрізний навчальний проєкт: портал продажу квитків на події (EventHub).
За семестр здобувачі вищої освіти будують працюючу систему з автентифікацією, платежами,
мікросервісами й розгортанням у продакшн.

**Спеціальність 122 «Комп'ютерні науки»**

## Гілки з кодом

Гілка `main` містить лише матеріали. Код проєкту живе в тижневих гілках.

| Тиждень | Тема                      | Старт                                       | Еталон                                    |
| ------- | ------------------------- | ------------------------------------------- | ----------------------------------------- |
| 1       | Архітектура й контракт    | [`week-01-start`](../../tree/week-01-start) | [`week-01-done`](../../tree/week-01-done) |
| 2       | Бекенд: шари й дисципліна | `week-02-start`                             | `week-02-done`                            |

_(таблиця поповнюється щотижня)_

## Як почати роботу

1. Ваша команда отримує власний репозиторій `eventhub-team-NN`, створений
   із цього шаблону. Працюєте **тільки в ньому**.
2. Клонуєте свій репозиторій, переходите на гілку `week-01-start`.
3. Виконуєте лабораторну за методичкою, робите PR у `main` **свого** репозиторію.
4. Далі щотижня продовжуєте зі свого `main` — гілки цього репозиторію більше
   не потрібні.

## Якщо відстали або зламали репозиторій

Гілки `week-NN-start` — рятувальні. Підхопитись із коректного стану:

```bash
git remote add course https://github.com/severyn-courses/eventhub.git
git fetch course
git checkout -b lab-05 course/week-05-start
```

## Правила

- Гілка на кожну лабораторну: `week-NN/<нік-автора>`
- PR у `main` свого репозиторію, рев'ю обов'язкове
- Ролі змінюються щотижня: **автор / рев'ювер / інтегратор**
- Кожне архітектурне рішення — документ у `docs/adr/`
