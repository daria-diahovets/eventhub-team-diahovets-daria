# @eventhub/config

Спільні налаштування інструментів для всіх пакетів монорепо.

- `tsconfig.base.json` — база TypeScript. Застосунки розширюють її та додають своє
  (`jsx`, `module`, `outDir`, декоратори тощо).
- `eslint.config.js` — база ESLint у форматі flat config.

Пакет навмисно не має власного коду й не збирається: це лише конфігурація.

## Чому `strict` увімкнено з першого дня

Вимкнути суворий режим потім легко, а ввімкнути на проєкті з 200 файлами —
кількаденна робота. `noUncheckedIndexedAccess` додатково змушує перевіряти
результат звернення за індексом: `items[0]` має тип `Event | undefined`,
і це чесно відображає реальність.
