# Каталог подій

Лабораторна № 1, крок 5: `EventList.tsx` — компонент, що показує список подій.

## Чому структура за фічами, а не за типами файлів

Порівняйте два варіанти:

```
src/components/   src/hooks/   src/services/     ← за типом файлу
src/features/catalog/  src/features/checkout/    ← за фічею
```

У першому випадку одна зміна («додати фільтр за містом») торкається трьох
папок, і жодна з них не розповідає, що взагалі вміє застосунок.

У другому — все, що стосується каталогу, лежить поруч. Нова людина в команді
відкриває `features/` і бачить перелік можливостей продукту. Видалити фічу —
видалити папку.

Це та сама ідея, що й обмежені контексти з лекції, лише на рівні файлів.
